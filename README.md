# AI Kanban App

## Run

### macOS / Linux
```bash
./scripts/start.sh
```

### Windows (PowerShell)
```powershell
.\scripts\start.ps1
```

Open: `http://localhost:8000`

## Restart

### macOS / Linux
```bash
./scripts/stop.sh
./scripts/start.sh
```

### Windows (PowerShell)
```powershell
.\scripts\stop.ps1
.\scripts\start.ps1
```

## Stop

### macOS / Linux
```bash
./scripts/stop.sh
```

### Windows (PowerShell)
```powershell
.\scripts\stop.ps1
```
